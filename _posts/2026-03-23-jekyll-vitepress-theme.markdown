Jekyll VitePress Theme brings the VitePress documentation UX to Jekyll as a reusable theme gem.

## Features

- VitePress-style docs layout (top nav, sidebar, outline, and doc footer)
- Local search modal (`/`, `Ctrl/Cmd+K`, `Cmd+K`)
- Appearance toggle (`auto`, `dark`, `light`)
- Code block copy buttons and language labels
- Optional GitHub star button with live count
- Jekyll-native extension hooks and YAML-first configuration
